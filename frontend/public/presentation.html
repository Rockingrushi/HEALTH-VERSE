01 / Problem & Solution

Problem Statement vs. The HealthVerse Solution

✕

Current Healthcare Challenges

  • • Information Asymmetry: Hospital bed availability and ICU capacity are not publicly visible in real time.
  • • Emergency Triage Delays: Patients spend crucial golden hours calling multiple hospitals to find oxygen and ventilators.
  • • Blood Bank Searching Friction: Finding matching blood units (e.g. O-, AB+) across scattered centers is slow and uncoordinated.
  • • Ambulance Fleet Opacity: Lack of insight into available vs. en-route emergency vehicles.
✓

The HealthVerse Solution

  • • Centralized Discovery Hub: Single-window portal uniting verified hospitals, beds, ICU, blood, and ambulances.
  • • Live Telemetry Sync: Direct hospital admin controls update bed counts, waiting time, and pharmacy instantly.
  • • 8-Group Blood Matrix: Real-time inventory tracking for A+, A-, B+, B-, AB+, AB-, O+, O-.
  • • Automated Email Alerts: Haversine distance-aware notifications sent to patients upon resource availability.

07 / Data Security

Database Design & Row Level Security (RLS)

🗄️ Relational PostgreSQL Schema

  • • hospitals: id, name, lat, lng, address, contact, is_approved, admin_id
  • • hospital_resources: hospital_id, total/available/icu beds, staff
  • • blood_inventory: hospital_id, blood_group, units_available
  • • ambulances: hospital_id, vehicle_number, status, contact
  • • health_alerts: user_id, alert_type, blood_group, radius_km, email
  • • email_notifications: recipient_email, subject, status, sent_at

🔒 RLS Security & Integrity Rules

  • • Public Access: Read-only access to approved hospitals (is_approved = true).
  • • Admin Scoping: Hospital Admins can only mutate resources where admin_id = auth.uid().
  • • Zero Secret Leakage: Service role keys & Resend secrets isolated to Python backend.
  • • Cascade Deletes: Foreign keys enforce data integrity upon hospital removal.
