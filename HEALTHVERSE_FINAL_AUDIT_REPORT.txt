10. BUGS FOUND
------------------------------------------

Bug: Blood Inventory State Shadowing
Severity: HIGH
Root Cause: Input onChange only updated local state, but mutation saved stale fetched query data.
Fix: Created updateBloodUnit handler to update state in-place and pass merged state object.
Verification: Verified blood unit updates persist to database and reflect on details page.

Bug: Stale Cache Serving in Hospital Details Page
Severity: HIGH
Root Cause: React Query default staleTime allowed cached hospital details to persist.
Fix: Added staleTime: 0 and refetchOnMount: "always" to all queries in HospitalProfile.tsx.
Verification: Verified Hospital Details updates immediately after Hospital Admin save.

Bug: Query Key Mismatch Between Admin and Profile Pages
Severity: MEDIUM
Root Cause: Admin dashboard invalidated ["hospital-resources"], while HospitalProfile queried ["hospital-resources", id].
Fix: Updated admin dashboard mutations to cross-invalidate hospital-specific keys.
Verification: Verified profile page updates without manual page refresh.

Bug: Missing Available Beds Validation
Severity: MEDIUM
Root Cause: No pre-save validation for available_beds <= total_beds or non-negative numbers.
Fix: Added explicit range validation throwing error if available beds exceed total beds or values are negative.
Verification: Verified error toast appears if invalid numbers are submitted.

Bug: Static Demo Data in HospitalComparison & Favorites
Severity: LOW
Root Cause: Comparison and Favorites pages referenced hardcoded mock IDs ("1", "3", "9").
Fix: Rewrote HospitalComparison.tsx and Favorites.tsx to query approved hospitals dynamically.
Verification: Verified real approved hospital cards and valid detail page links.

Bug: Unused Imports Causing Build Errors
Severity: LOW
Root Cause: Unused icon imports (e.g. Star in HospitalComparison.tsx).
Fix: Cleaned up unused imports across components.
Verification: npx tsc --noEmit and npm run build both pass with Exit Code 0.
